# Atlas Cowork

Obsidian plugin: chat with the current note or canvas, brainstorm on a canvas, save answers as notes. Uses our Atlas model.

## Install (desktop or mobile)

1. Install **BRAT** from Obsidian community plugins.
2. BRAT → *Add Beta plugin* → `viktorhorou/atlas-cowork`.
3. Enable **Atlas Cowork** in Community plugins.
4. Settings → Atlas Cowork: set the endpoint (default is the tailnet Atlas URL) and model.

Manual: copy `main.js`, `manifest.json`, `styles.css` into `<vault>/.obsidian/plugins/atlas-cowork/`.

## Requirements

- Access to the Atlas endpoint over Tailscale/LAN.
- Obsidian 1.5+.
